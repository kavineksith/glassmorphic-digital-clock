<digital-clock> — reusable web component

A config-driven, glassmorphic digital clock. Drop dist/ anywhere, include dist/digital-clock.js, and use <digital-clock>. Theme, fonts, glass blur, animated gradient border, background image / slideshow / neon gradient, 12 / 24-hour format, time zones and locale all live in dist/config.json. Click the gear to tweak live — press S to toggle settings, Esc to close.

Same component, different attributes — fully reusable
Bonus themes — emerald / ruby / matrix / ice
Slideshow config — rotates 5 copyright-free Pexels photos every 6s
Quick start 
<script src="dist/digital-clock.js"></script>
<digital-clock></digital-clock>

<!-- per-clock overrides via attributes -->
<digital-clock theme="matrix" format="12" timezone="Asia/Colombo"></digital-clock>

<!-- built-in slideshow config (rotates the sample wallpapers) -->
<digital-clock config="dist/config-slideshow.json"></digital-clock>

<!-- your own config file -->
<digital-clock config="/path/to/my-config.json"></digital-clock>

Or drive it imperatively:

const clock = document.querySelector('digital-clock');
clock.setConfig({ style: { theme: 'ruby' }, clock: { format: '12' } });
clock.getConfig();   // -> current merged config
clock.resetConfig(); // -> back to defaults
